# Token Move 2.7 — attach และเอฟเฟกต์อิสระ

## สิ่งที่เปลี่ยน
- บนแผนที่เหลือเฉพาะเลขจุด 1, 2, 3… เอาป้ายช่วง 1→2 และ 2→3 ออกแล้ว ตัวเลขเวลาเดินในรายการตั้งค่ายังอยู่
- เลือก Token หลัก หรือชิ้นที่ attach ซ้อนอยู่แล้วเพิ่มกลุ่มได้ ระบบหาตัวหลักและควบคุมแต่ละชุดเพียงครั้งเดียว
- LINE แสดงการเคลื่อนที่ของชิ้นแนบทุกชั้นด้วย ไม่แยกหรือเปลี่ยน attachedTo
- เปลี่ยนชื่อโหมดอยู่กับที่เป็น **เอฟเฟกต์อิสระ**: ไม่มีการเดิน LINE อัตโนมัติ แต่สั่น/ดุ๊กดิ๊กต่อได้ขณะคุณใช้เครื่องมือย้าย/หมุน/ปรับขนาด Token
- ปิดเอฟเฟกต์แล้วเก็บตำแหน่งและองศาฐานที่ปรับล่าสุด ไม่ดึงกลับตำแหน่งตอนเริ่ม

## ใช้งาน attach
เลือกส่วนใดส่วนหนึ่งของชุด → เพิ่มกลุ่ม → ใช้ LINE หรือเอฟเฟกต์อิสระ
เมื่อเลือกทั้งตัวหลักและชิ้นแนบพร้อมกันจะนับเป็นชุดเดียว จึงไม่เกิดการขยับซ้ำ
ตัวหลักต้องปลดล็อกก่อนเริ่ม หากไม่พบตัวหลักหรือมีวงวนการ attach จะแจ้งให้แก้ก่อน
ระบบเคารพการตั้งค่า attachment behavior ของ Owlbear; ชิ้นที่ปิดตามตำแหน่ง/การหมุน/ขนาดจะไม่ถูกบังคับให้ตามคุณสมบัตินั้น
ถ้าเปลี่ยนการ attach ของตัวหลักระหว่างกำลังทำงาน ให้หยุดแล้วเลือกชุดใหม่

## ใช้งานเอฟเฟกต์อิสระ
1. เพิ่มกลุ่มจาก Token ที่เลือก
2. เลือก **เอฟเฟกต์อิสระ** แล้วเลือกสั่นหรือดุ๊กดิ๊ก
3. กด ▶ เพื่อเปิดเอฟเฟกต์ จากนั้นใช้เครื่องมือย้าย/หมุน/ปรับขนาดได้
4. กด ■ หรือ ⋯ → ปิดเอฟเฟกต์ เพื่อเอาการสั่น/ดุ๊กดิ๊กออกจากตำแหน่ง/องศาล่าสุด
ถ้าเลือกชิ้นแนบ ระบบจะใส่เอฟเฟกต์ให้ทั้งชุดผ่าน Token หลัก
กลุ่มเก่าที่ใช้โหมดอยู่กับที่จะโหลดเป็นเอฟเฟกต์อิสระให้เอง เส้นทาง LINE เดิมยังเก็บไว้
เอฟเฟกต์อิสระแก้เฉพาะตำแหน่งสำหรับสั่น และแก้เฉพาะองศาสำหรับดุ๊กดิ๊ก ไม่ถือ interaction ที่ควบคุมตำแหน่งตลอดเวลา
รับตำแหน่ง/องศาใหม่จากเครื่องมือเมื่อการแก้ไขนั้นส่งเข้าฉากแล้ว ปรับได้ต่อเนื่องหลังเครื่องมือจบการลาก

## ใช้งาน
เลือก Token บนแผนที่ → เพิ่มกลุ่ม → เดิน LINE → คลิกช่องเริ่มและช่องถัดไป → Enter หรือคลิกจุดล่าสุดซ้ำเพื่อบันทึก
กด ▶ เพื่อเดิน, ■ เพื่อหยุด, ⋯ เพื่อปรับรายละเอียด กลุ่มต่าง ๆ ทำงานแยกกัน
เอฟเฟกต์อิสระใช้สั่นหรือดุ๊กดิ๊กโดยไม่ต้องวาด LINE และยังใช้เครื่องมือย้ายได้

## หมายเลขและเวลาเดิน
แสดงเลข 1, 2, 3… บนแผนที่ของ GM ให้ตรงกับรายการตั้งค่า (ไม่มีป้ายช่วงบนเส้นแล้ว)
เส้นแสดงเฉพาะกลุ่มที่เลือกและซ่อนได้ เมื่อคลิก ⋯ จะเลือกกลุ่มนั้นให้
กด ⋯ → เวลาเดิน · จุดพัก · เอฟเฟกต์รายจุด
แต่ละช่วงแสดงเวลาจากระยะพิกเซล ÷ ขนาดกริด ÷ ความเร็ว (ช่อง/วินาที) ขั้นต่ำ 0.1 วินาทีต่อช่วง ไม่รวมเวลาพัก
ตัวอย่าง ระยะ 4 ช่อง ความเร็ว 2 ช่อง/วินาที = 2 วินาที
เปลี่ยนความเร็วกลุ่มเพื่อเปลี่ยนเวลาเดิน ตัวเลขแสดงระยะตรงระหว่างจุดที่วาดไว้ ใช้ระยะจริงสำหรับแนวทแยง ไม่ใช่กฎนับระยะในเกม
ค่อย ๆ ออกตัวและหยุดเปลี่ยนจังหวะภายในช่วง แต่เวลาแต่ละช่วงเท่าเดิม
แสดงเวลาเต็มช่วงตั้งแต่จุดก่อนหน้าถึงจุดถัดไป ไม่ใช่เวลาที่เหลือหลังหยุดกลางทาง
ขณะเดินแสดงช่วงปัจจุบัน ขณะพักแสดงหมายเลขจุดและเวลาที่เหลือ

## เวลาพักและเอฟเฟกต์แยกแต่ละจุด
1. หยุดกลุ่ม → ⋯ → เวลาเดิน · จุดพัก · เอฟเฟกต์รายจุด
2. ข้างจุดที่ต้องการพัก ใส่วินาที (0–3600 ทีละ 0.1); 0 คือผ่านเลย
3. เลือกตามเอฟเฟกต์กลุ่ม / หยุดนิ่ง / ดุ๊กดิ๊กตอนพัก / สั่นตอนพัก
4. คลิกออกจากช่องหรือกด Enter เพื่อบันทึก แล้วกด ▶
ตัวอย่าง เอฟเฟกต์กลุ่ม = ปกติ, จุด 2 = 5 วินาที + ดุ๊กดิ๊กตอนพัก: เดินปกติ → ถึงจุด 2 หมุนซ้ายขวา 5 วินาที → คืนองศาเดิมแล้วเดินต่อ
ปรับองศา/จังหวะได้ที่ ⋯ โดยใช้ค่าเดียวกันในกลุ่มนั้น
เลือกเอฟเฟกต์อย่างเดียวแต่พัก 0 วินาทีจะไม่แสดงเอฟเฟกต์ที่จุดนั้น
วนไปกลับพักและใช้เอฟเฟกต์ที่ตั้งไว้ทุกครั้งที่ถึงจุดนั้นทั้งขาไปและขากลับ
จุด 1 ออกเดินทันทีในรอบแรก และใช้เวลาพักเมื่อเดินกลับมาถึง
กดหยุดระหว่างพักจะคืนท่าเดิม เมื่อเริ่มต่อจะนับเวลาพักที่เหลือต่อ
วาด LINE ใหม่ล้างเวลาพักและเอฟเฟกต์รายจุดเพื่อไม่ให้ผูกกับจุดผิด เปลี่ยนช่องเริ่มอย่างเดียวเก็บค่าเดิม
บันทึกการตั้งค่าในฉากได้; รีโหลดโหลดค่าโดยไม่เริ่มเดินเอง แต่ไม่เก็บสถานะนับเวลาค้าง
