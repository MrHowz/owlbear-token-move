# Token Move 2.2 — LINE อย่างเดียว เลือกจุดเริ่มเอง

Extension ภาษาไทยสำหรับ GM ใน Owlbear Rodeo ให้ Token หลายตัวเดินตามเส้นทางแยกเป็นหลายกลุ่ม พร้อม Loop ไปกลับและ Flip ตามทิศเดิน

## เริ่มใช้งาน

1. เลือก Token ที่ปลดล็อกแล้วหนึ่งตัวหรือหลายตัวบนแผนที่
2. เปิด Token Move กด **เพิ่มกลุ่มจาก Token ที่เลือก**
3. กด **สร้าง LINE** แผงจะปิดให้เลือกช่องบนแผนที่
4. **คลิกช่องเริ่มต้นเองเป็นจุดแรก** ไม่จำเป็นต้องตรงกับตำแหน่ง Token ตอนเพิ่มกลุ่ม
5. คลิกช่องถัดไปตามลำดับที่ต้องการเดิน อย่างน้อยอีกหนึ่งช่อง
6. **คลิกช่องล่าสุดซ้ำเพื่อบันทึก** หรือกด Enter แผงจะเปิดกลับมา
7. เลือกความเร็ว เดินครั้งเดียวหรือวนไปกลับ และการหันหน้า แล้วกด **เริ่มเดิน** การตั้งค่าที่แก้ไว้จะบันทึกก่อนเริ่มให้

เมื่อเริ่มรอบแรกหลังสร้าง/แก้ LINE หรือโหลดห้องใหม่ ระบบวาง Token ตัวอ้างอิงที่ช่องเริ่มที่เลือกก่อนเดิน สมาชิกอื่นคงระยะห่างเดิมของกลุ่ม การสร้างหรือแก้เส้นทางอย่างเดียวยังไม่ย้าย Token

กด **หยุด** แล้ว **เดินต่อ** จะเคลื่อนจากจุดที่หยุดไว้ตาม LINE เดิม ไม่ย้ายกลับจุดเริ่ม ระหว่าง Loop จะย้อนผ่านทุกจุดเดิมและ Flip ตามทิศเดิน เมื่อเดินครั้งเดียวจบ กดเริ่มรอบใหม่เพื่อกลับไปเริ่ม LINE เดิมได้

## เปลี่ยนจุดเริ่มโดยไม่วาด LINE ใหม่

หยุดกลุ่ม → กด **เปลี่ยนจุดเริ่ม** → คลิกช่องเริ่มใหม่ เส้นทางจุดถัดไปคงเดิม กดเริ่มเมื่อพร้อม ไม่มีการผูกจุดเริ่มกับตำแหน่งตอนเพิ่มกลุ่ม

หากเปลี่ยนไปช่องเดียวกับจุดถัดไป ระบบรวมจุดซ้ำติดกัน ต้องเหลืออย่างน้อยสองจุดที่ต่างกัน

## ระหว่างวาด LINE

| การกด | ผล |
| --- | --- |
| คลิกช่อง | เพิ่มจุดที่กึ่งกลางช่องกริด |
| คลิกช่องล่าสุดซ้ำ | บันทึก LINE เมื่อมีอย่างน้อยสองจุด |
| Enter | บันทึก LINE |
| Backspace | ย้อนหนึ่งจุด รวมถึงลบช่องเริ่มที่เลือกเพื่อเลือกใหม่ได้ |
| Esc | ยกเลิกร่างและเก็บ LINE เดิม |

เปิดแผงขึ้นมาระหว่างเลือกช่องได้ มีปุ่ม **บันทึก LINE**, **ย้อน 1 จุด**, **ยกเลิก** ขนาดใหญ่ติดด้านล่าง รองรับสูงสุด 501 จุดรวมจุดเริ่ม

LINE เชื่อมช่องตามลำดับที่คลิก หากต้องการกำหนดทุกช่องให้คลิกช่องติดกัน ไม่ค้นหาเส้นทางหรือหลบกำแพงให้เอง

## หน้าควบคุมใหม่

- เหลือเส้นทาง LINE อย่างเดียว ตัดปุ่ม A/B และการเลือกปลายทางจากวัตถุออก
- เลือกกลุ่มจากรายการด้านบน เพิ่มกลุ่มใหม่ได้ขณะที่กลุ่มอื่นเดิน
- ความเร็วมีปุ่ม −/+ ปุ่มเลือกรูปแบบเดินแสดงทั้งสองตัวเลือก และมีตัวเลือกหันหน้าตามทางเดิน
- ปุ่มเริ่มและหยุดอยู่ด้านล่างเสมอ เลื่อนอ่านการตั้งค่าก็กดได้
- ชื่อกลุ่มแก้ได้โดยตรง การตั้งค่าที่แก้จะบันทึกเมื่อกดเริ่มหรือย้ายไปทำรายการอื่น หรือกดบันทึกในแถบการตั้งค่าใหม่
- **ตัวเลือกเพิ่มเติม** เก็บพิกัดแต่ละช่อง รูปต้นฉบับหันซ้าย/ขวา การค่อย ๆ ออกตัว เปลี่ยน Token กลับจุดเริ่ม และลบกลุ่ม
- เปลี่ยน Token จะเก็บ LINE เดิมและใช้ระยะห่างของสมาชิกชุดใหม่ ส่วนลบกลุ่มไม่ลบ Token บนแผนที่

## หลายกลุ่มและการหันหน้า

เลือก Token ชุดอื่นแล้วเพิ่มกลุ่มใหม่ได้ แต่ละกลุ่มมี LINE ความเร็วและรูปแบบเดินแยกกัน หากมีหลายกลุ่มจะมีปุ่มเริ่มทั้งหมดและหยุดทั้งหมด กลุ่มที่ใช้ Token ซ้ำกับกลุ่มกำลังเดินเริ่มพร้อมกันไม่ได้

Flip ใช้กับรูปภาพและคงขนาด/การหมุนเดิม ตั้งทิศภาพต้นฉบับในตัวเลือกเพิ่มเติม หากภาพแต่ละตัวหันคนละด้าน ควรแยกกลุ่ม แนวตั้งจะสลับ Flip ในเที่ยวกลับ

## บันทึกและอัปเดตจากรุ่นเดิม

ข้อมูลเก็บใน Scene แยกตาม ID ผู้ควบคุม หลังรีโหลดกลุ่มจะกลับมาในสถานะหยุด รุ่น 2.0/2.1 เดิมจะย้ายมาเป็น LINE อัตโนมัติ เส้นตรงเดิมกลายเป็น LINE สองจุด ส่วน LINE เดิมเก็บจุดทั้งหมดและเพิ่มจุดเริ่มเดิมเป็นจุดแรก จากนั้นเปลี่ยนจุดเริ่มได้เลย

หากกลุ่มเก่าเริ่มและจบช่องเดียวกันจนเหลือจุดเดียว ระบบเก็บสมาชิกไว้และให้สร้าง LINE ใหม่ รุ่น 2.2 ใช้ข้อมูลบันทึก version 3 จึงควรใช้ชุด 2.2 ทั้งแผงและ background

## อัปเดตผ่าน GitHub / Netlify

1. แตก **token-move-v2.2-source.zip**
2. เปิด repository เดิม → Code → Add file → Upload files
3. อัปโหลดไฟล์และโฟลเดอร์ข้างในทั้งหมด รวม `src`, `public`, `tests` รวม 22 ไฟล์ โดย `package.json` อยู่บนสุด
4. Commit เข้า main รอ Netlify build และ Published
5. เปิด `/manifest.json` แล้วรีโหลด ต้องเห็น version **2.2.0** และชื่อ **Token Move • LINE**
6. หยุดกลุ่มในห้องก่อน กด Ctrl + Shift + R เปิดแผงใหม่ แล้วกดเริ่มเมื่อพร้อม

Netlify ใช้ `npm run build`, Publish directory `dist`, Node 22 ตาม `netlify.toml` หรือใช้ **token-move-v2.2-hosting.zip** แตกไฟล์แล้วอัปโหลดโฟลเดอร์ที่มี `index.html`, `background.html`, `manifest.json`, `icon.svg`, `_headers`, `assets/` โดยตรงไป Deploys โปรเจกต์เดิม การอัปโหลดไฟล์พร้อมโฮสต์ไม่อัปเดต GitHub

manifest ใช้ `/index.html`, `/background.html`, `/icon.svg` ให้โฮสต์ที่ root ของ HTTPS domain เก็บ `_headers` ไว้ด้วยเพื่อเปิด CORS บน Netlify URL ติดตั้งเดิมใช้ต่อได้

## ข้อจำกัด

ต้องเป็น GM และเปิด Scene ค้างไว้ ปิดแผงได้ แต่การรีโหลด เปลี่ยน Scene เสียสิทธิ์ GM หรือเครื่อง sleep จะหยุดงาน เปิดห้องใหม่ต้องเริ่มเอง เลือกวัตถุหลักที่ไม่ถูกล็อก ลูกที่แนบจะตามพฤติกรรม attachment ของ Owlbear หยุดกลุ่มก่อนลากหรือแก้วัตถุด้วยมือ

ขนาด Token ไม่เปลี่ยน จุดเริ่มเป็นจุดอ้างอิงของสมาชิกตัวแรก ตัวอื่นคงระยะห่างเดิม ควรวางสมาชิกให้ตรงกริดก่อนเพิ่มกลุ่ม หากเปลี่ยนชนิด/ขนาดกริดภายหลังควรวาด LINE ใหม่

การอัปเดตการเดินใช้เป้าหมาย 60 ครั้ง/วินาที และเตรียม interaction ใหม่ระหว่างตัวเดิมยังเดินอยู่จากรุ่น 2.1.1 เฟรมเรตจริงขึ้นกับเบราว์เซอร์ Owlbear เครื่องและเครือข่าย ไม่ควรสั่ง Token เดียวกันจากหลายแท็บหรือหลายบัญชี GM พร้อมกัน

## พัฒนาและตรวจสอบ

ใช้ Node.js 22.12 ขึ้นไป รัน `npm ci`, `npm test`, `npm run build` ในโฟลเดอร์ซอร์ส ส่วน `npm run dev` เปิดเซิร์ฟเวอร์พัฒนา หน้าภายนอก Owlbear เป็นตัวอย่าง กดควบคุมจริงได้เมื่อฝังในห้อง

ผ่าน 43 tests และ production build รวมจุดเริ่มอิสระ รักษาระยะสมาชิก เปลี่ยนจุดเริ่มโดยเก็บจุดอื่น หยุด/เดินต่อ เริ่มใหม่หลังจบรอบ ย้ายข้อมูลรุ่นเดิม และกรณีตอบกลับช้าจากรุ่น 2.1.1 ตรวจ UI กับ SDK ในห้องจำลองภายในเครื่อง ยังต้องลองรุ่นนี้ในห้องจริงหลังอัปเดตเพื่อยืนยันภาพและการซิงก์หลายเครื่อง
