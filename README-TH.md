# Token Move 2.3 — แผง LINE แบบรายการ

Extension ภาษาไทยสำหรับ GM ใน Owlbear Rodeo ให้ Token เดินตาม LINE ที่เลือกเอง แยกหลายกลุ่มได้ มีวนไปกลับและ Flip ตามทิศเดิน

## เริ่มใช้งาน

1. เลือก Token ที่ปลดล็อกแล้วบนแผนที่หนึ่งตัวหรือหลายตัว
2. เปิด Token Move กด **เพิ่มกลุ่มจาก Token ที่เลือก**
3. ในแถวกลุ่ม กดปุ่มใต้หัวข้อ **LINE** แผงจะปิดให้เลือกช่องบนแผนที่
4. คลิกช่องเริ่มเองเป็นจุดแรก แล้วคลิกช่องถัดไปตามลำดับ อย่างน้อยสองจุดที่ต่างกัน
5. คลิกช่องล่าสุดซ้ำ หรือกด Enter เพื่อบันทึก แผงจะเปิดกลับมา
6. ปรับความเร็ว วนกลับ และ Flip จากปุ่มวงกลมของแถวนั้น แล้วกด **▶**

จุดเริ่มเลือกใหม่ได้อิสระ ไม่ผูกกับตำแหน่งตอนเพิ่มกลุ่ม รอบแรกหลังสร้าง/แก้ LINE หรือโหลดห้อง ระบบวาง Token อ้างอิงที่ช่องเริ่มก่อนเดิน ตัวอื่นคงระยะห่างเดิม การวาดเส้นทางอย่างเดียวยังไม่ย้าย Token

## ปุ่มในแต่ละแถว

| ตัวควบคุม | การใช้งาน |
| --- | --- |
| LINE | วาดเส้นทางใหม่ รวมช่องเริ่มใหม่ |
| ช่อง/วิ | พิมพ์ความเร็ว 0.1–20 ช่องต่อวินาที แล้วกด Enter หรือคลิกออกเพื่อบันทึก |
| วนกลับ | เปิดให้เดินไปกลับผ่านทุกจุดเดิม ปิดเพื่อเดินครั้งเดียว |
| Flip | เปิดให้รูปภาพหันตามทิศเดิน |
| ▶ / ■ | เริ่มหรือเดินต่อ / หยุด เฉพาะกลุ่มนั้น |
| ⋯ หรือชื่อกลุ่ม | เปิด/พับรายละเอียดของกลุ่ม |

สวิตช์ที่เปิดมีพื้นสีม่วง ปุ่มหยุดเป็นสีส้ม ข้างชื่อบอกจำนวน Token จำนวนจุด และสถานะเดิน/พัก มีแถบความคืบหน้าใต้แถว ปุ่ม ▶ และ ■ บนหัวสีม่วงใช้เริ่มทุกกลุ่มและหยุดทุกกลุ่ม

ค่าที่แก้จะบันทึกอัตโนมัติเมื่อกดสวิตช์หรือแก้ช่องแล้วคลิกออก ค่าที่กำลังพิมพ์จะบันทึกก่อนเริ่มหรือแก้เส้นทางด้วย ระหว่างเดินปุ่มแก้ค่าของกลุ่มนั้นจะจางลง หยุดก่อนแก้ไข สามารถควบคุมแถวอื่นได้ตามปกติ

## รายละเอียดใน ⋯

- แก้ชื่อกลุ่ม
- **เลือกจุดเริ่ม**: คลิกช่องแรกใหม่โดยเก็บจุดถัดไปของ LINE เดิม
- แสดง/ซ่อนเส้นทางตัวอย่างของกลุ่มที่เลือก
- ค่อย ๆ ออกตัวและหยุด และทิศที่รูปต้นฉบับหันซ้าย/ขวา
- เปิดดูรายการพิกัดเมื่อจำเป็น
- เปลี่ยน Token ของกลุ่ม กลับจุดเริ่ม หรือลบกลุ่ม

เปลี่ยน Token เก็บ LINE เดิมและใช้ระยะห่างของสมาชิกชุดใหม่ ลบกลุ่มไม่ลบ Token บนแผนที่ หากเปลี่ยนจุดเริ่มเป็นช่องเดียวกับจุดถัดไป ระบบรวมจุดซ้ำติดกัน ต้องเหลืออย่างน้อยสองจุด

## วาด LINE บนกริด

| การกด | ผล |
| --- | --- |
| คลิกช่อง | เพิ่มจุดที่กึ่งกลางช่องกริด |
| คลิกช่องล่าสุดซ้ำ หรือ Enter | บันทึกเมื่อมีอย่างน้อยสองจุด |
| Backspace | ย้อนหนึ่งจุด รวมถึงลบช่องเริ่มเพื่อเลือกใหม่ |
| Esc | ยกเลิกร่างและเก็บ LINE เดิม |

เปิดแผงระหว่างเลือกช่องได้ จะมีปุ่มบันทึก LINE ย้อนจุด และยกเลิก รองรับสูงสุด 501 จุดรวมจุดเริ่ม เส้นเชื่อมตามลำดับที่คลิก หากต้องการกำหนดทุกช่องให้คลิกช่องติดกัน ระบบไม่ค้นหาเส้นทางหรือหลบกำแพงให้เอง

## หลายกลุ่มและการเดินต่อ

แต่ละกลุ่มมีเส้นทางและค่าการเดินแยกกัน หยุดกลุ่มหนึ่งแล้วอีกกลุ่มเดินต่อได้ กลุ่มที่ใช้ Token ซ้ำกับกลุ่มกำลังเดินเริ่มพร้อมกันไม่ได้

กดหยุดแล้ว ▶ จะเดินต่อจากจุดที่หยุด เมื่อเดินครั้งเดียวจบ กด ▶ อีกครั้งเพื่อเริ่มรอบใหม่ที่ช่องเริ่ม Flip ใช้กับรูปภาพโดยคงขนาดและการหมุน หากภาพสมาชิกหันคนละด้านควรแยกกลุ่ม แนวตั้งจะสลับ Flip ในเที่ยวกลับ

## ข้อมูลจากรุ่นเดิม

ข้อมูลเก็บใน Scene แยกตามผู้ควบคุม ใช้รูปแบบบันทึก version 3 เช่นเดียวกับ 2.2 จึงเก็บกลุ่มและเส้นทาง 2.2 ต่อได้ หลังโหลดห้องทุกกลุ่มหยุดและรอให้กดเริ่มเอง

ข้อมูล 2.0/2.1 ย้ายมาเป็น LINE อัตโนมัติ เส้น A/B เดิมกลายเป็นสองจุด LINE เดิมเพิ่มจุดเริ่มเดิมเป็นจุดแรก หากเหลือจุดเดียวระบบเก็บสมาชิกและให้วาดเส้นทางใหม่ ควรอัปเดตทั้งแผงและ background จากชุดเดียวกัน

## อัปเดตผ่าน GitHub / Netlify

1. แตก **token-move-v2.3-source.zip**
2. เปิด repository เดิม → Code → Add file → Upload files
3. ลากไฟล์และโฟลเดอร์ข้างในทั้งหมด รวม `src`, `public`, `tests` รวม 23 ไฟล์ โดย `package.json` อยู่บนสุด
4. Commit เข้า main รอ Netlify build และ Published
5. เปิด `/manifest.json` แล้วรีโหลด ต้องเห็น version **2.3.0**
6. หยุดกลุ่มในห้องก่อน กด Ctrl + Shift + R แล้วเปิด Token Move ใหม่

Netlify ใช้ `npm run build`, Publish directory `dist`, Node 22 ตาม `netlify.toml` หรือแตก **token-move-v2.3-hosting.zip** แล้วอัปโหลดโฟลเดอร์ที่มี `index.html`, `background.html`, `manifest.json`, `icon.svg`, `_headers`, `assets/` ไป Deploys โปรเจกต์เดิมโดยตรง วิธีหลังไม่อัปเดตซอร์สใน GitHub

URL ติดตั้งเดิมใช้ต่อได้ manifest ใช้ `/index.html`, `/background.html`, `/icon.svg` สำหรับ HTTPS domain ที่ root เก็บ `_headers` เพื่อเปิด CORS บน Netlify มีการตรวจข้อกำหนด manifest ก่อน build รวมความยาว description ไม่เกิน 128 ตัวอักษร

## ข้อจำกัด

ต้องเป็น GM และเปิด Scene ค้างไว้ ปิดแผงได้ แต่รีโหลด เปลี่ยน Scene เสียสิทธิ์ GM หรือเครื่อง sleep จะหยุดงาน เปิดห้องใหม่ต้องเริ่มเอง เลือกวัตถุหลักที่ไม่ถูกล็อก ลูกที่แนบตามพฤติกรรม attachment ของ Owlbear หยุดกลุ่มก่อนลากหรือแก้วัตถุด้วยมือ

ขนาด Token ไม่เปลี่ยน จุดเริ่มเป็นจุดอ้างอิงสมาชิกตัวแรก ตัวอื่นคงระยะห่างเดิม ควรวางสมาชิกให้ตรงกริดก่อนเพิ่มกลุ่ม หากเปลี่ยนชนิด/ขนาดกริดภายหลังควรวาด LINE ใหม่

การเดินใช้เป้าหมาย 60 ครั้ง/วินาทีและเตรียม interaction ใหม่ระหว่างตัวเดิมยังเดินอยู่ เฟรมเรตจริงขึ้นกับ Owlbear เบราว์เซอร์ เครื่องและเครือข่าย ไม่ควรสั่ง Token เดียวกันจากหลายแท็บหรือหลายบัญชี GM พร้อมกัน
