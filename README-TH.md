# Token Move — Extension สำหรับ Owlbear Rodeo

เคลื่อน Token หรือวัตถุจาก A ไป B อัตโนมัติ ปรับความเร็วได้ และเลือกวนไปกลับ A ↔ B ได้ หน้าควบคุมภาษาไทย ใช้โดย GM

## ติดตั้งแบบพร้อมใช้

1. แตกไฟล์ `token-move-hosting.zip` จะได้ `manifest.json`, `index.html`, `background.html`, `icon.svg`, `_headers` และโฟลเดอร์ `assets`
2. นำไฟล์ทั้งหมดขึ้น static hosting ที่ให้บริการ HTTPS เช่น Netlify, Cloudflare Pages หรือ GitHub Pages โดยให้ไฟล์เหล่านี้อยู่ในโฟลเดอร์เดียวกันและคงโครงสร้าง `assets` ไว้
3. ตรวจว่าเปิด `https://ชื่อเว็บของคุณ/manifest.json` ได้จริง ถ้าโฮสต์ใต้โฟลเดอร์ย่อย ให้ใช้ URL ของโฟลเดอร์นั้น
4. เข้า Owlbear Rodeo ไปที่หน้า Extensions → Add Extension แล้ววาง URL ของ `manifest.json` จากนั้นเพิ่มหรือเปิดใช้งานในห้องที่ต้องการ
5. เปิด Scene และเข้าในฐานะ GM กดไอคอนลูกศร Token Move เพื่อเปิดแผงควบคุม

ไฟล์ ZIP ต้องแตกก่อนนำไปโฮสต์ Owlbear Rodeo ไม่ได้ติดตั้ง Extension ด้วยการอัปโหลด ZIP โดยตรง และยังไม่มี URL สาธารณะให้จนกว่าจะนำไฟล์ขึ้นโฮสต์

### หาก Owlbear แสดง Failed to fetch

ตรวจว่า URL ลงท้ายด้วย `/manifest.json` และเปิดแล้วเห็น JSON ของ Token Move ไฟล์ `_headers` ในชุดนี้ตั้งค่า CORS สำหรับ Netlify เพื่อให้เว็บอื่นอ่านไฟล์ Extension สาธารณะได้ ต้องอัปโหลด `_headers` ไว้ระดับเดียวกับ `index.html` แล้ว deploy ใหม่ การตรวจว่า manifest เปิดได้อย่างเดียวไม่ได้ยืนยันว่าเบราว์เซอร์อ่านข้ามเว็บไซต์ได้ หากยังผิดพลาดให้ตรวจ response headers และข้อความใน browser console ของ Owlbear เพิ่มเติม

## วิธีใช้

1. ใช้เครื่องมือเลือกของ Owlbear Rodeo เลือก Token หรือวัตถุหนึ่งชิ้นหรือหลายชิ้นที่ปลดล็อกแล้ว
2. เปิด Token Move กด **บันทึกจุด A จากวัตถุที่เลือก** ตำแหน่งของวัตถุชิ้นแรกเป็นจุดอ้างอิง A
3. กด **เลือกจุด B บนแผนที่** แผงจะปิดลง ให้คลิกปลายทางบนฉาก แผงจะเปิดกลับมา กด Esc เพื่อยกเลิกได้
4. ตั้งความเร็วเป็นจำนวนช่องกริดต่อวินาที เลือกเที่ยวเดียวหรือวนไปกลับ และเลือกค่อย ๆ ออกตัวและหยุดได้
5. กด **เริ่มเคลื่อนที่** วัตถุทั้งหมดเคลื่อนพร้อมกันโดยรักษาระยะห่างเดิม จุด B เป็นปลายทางของตำแหน่งอ้างอิงวัตถุชิ้นแรก
6. กด **หยุด** เพื่อหยุดและบันทึกตำแหน่งปัจจุบัน หรือ **กลับจุด A** เพื่อหยุดและย้ายทุกชิ้นกลับตำแหน่งเริ่มต้นทันที

กดเริ่มหลังหยุดจะเคลื่อนจากตำแหน่งปัจจุบันไป B ถ้าถึง B แล้วและต้องการเริ่มใหม่ ให้กดกลับจุด A ก่อน เลือกวัตถุชุดใหม่ได้ด้วยการบันทึก A ใหม่

## ขอบเขตการทำงาน

- ควบคุมได้เฉพาะ GM วัตถุต้องเป็น scene items ที่ SDK แก้ไข position ได้ เช่น Token, Prop, รูปภาพ, รูปร่าง และข้อความ
- วัตถุที่ล็อกต้องปลดล็อกก่อน วัตถุแนบให้เลือกวัตถุหลัก ลูกที่แนบจะเคลื่อนตามพฤติกรรม attachment ของ Owlbear Rodeo
- ใช้เส้นทางตรง ไม่ค้นหาเส้นทาง ไม่หลบกำแพง ไม่คำนวณระยะเดินตามกฎเกม และไม่บังคับ snap เข้ากริด
- ความเร็วอ้างอิงขนาด DPI ของกริด แม้ฉากจะซ่อนกริดอยู่ โหมดค่อย ๆ ออกตัวใช้เวลาเดินทางเท่าเดิมแต่ความเร็วระหว่างทางเปลี่ยนไป
- ทำงานใน background จึงปิดแผงควบคุมได้ แต่ต้องเปิดห้องในเบราว์เซอร์ของ GM ผู้สั่งงานไว้ การปิดห้อง รีโหลด เปลี่ยน Scene หรือเสียสิทธิ์ GM จะยุติงาน ไม่มีระบบย้ายงานไป GM คนอื่นหรือกู้คืนหลังรีโหลด
- ควรให้ GM คนเดียวควบคุมวัตถุชุดเดียวในเวลาเดียวกัน และหลีกเลี่ยงลากวัตถุด้วยมือระหว่างเคลื่อนที่
- เบราว์เซอร์ที่พักแท็บหรือคอมพิวเตอร์ที่ sleep อาจทำให้การเคลื่อนที่สะดุดหรือหยุด ควรเปิดแท็บห้องไว้ขณะใช้งาน
- จุด A/B และชุดวัตถุเก็บชั่วคราวใน background ของผู้ควบคุม ไม่ถูกบันทึกลง Scene

## พัฒนาต่อจากซอร์ส

ใช้ Node.js 22.12 ขึ้นไป เปิด terminal ในโฟลเดอร์นี้แล้วรัน:

```sh
npm ci
npm run dev
```

`npm run build` ตรวจ TypeScript และสร้างเว็บไซต์พร้อมโฮสต์ใน `dist/` ส่วน `npm test` ทดสอบการเคลื่อนที่ด้วย SDK adapter จำลอง เปิดหน้าเว็บตรง ๆ จะเห็นหน้าตาตัวอย่าง ปุ่มควบคุมใช้งานได้เมื่อฝังใน Owlbear Rodeo เท่านั้น

## การตรวจสอบรุ่นนี้

ผ่านการตรวจ TypeScript, production build และชุดทดสอบการคำนวณ/วงจรการเคลื่อนที่ รวมถึงหลายวัตถุ หยุดกลางทาง วนกลับ และต่ออายุ interaction ระยะยาว ยังไม่ได้ทดสอบในห้อง Owlbear Rodeo จริงหรือยืนยันการซิงก์ระหว่างผู้เล่นหลายเครื่อง จึงควรลองกับ Token ทดสอบก่อนใช้งานในเกม

`npm audit` รายงานช่องโหว่ระดับ moderate ใน `uuid` ที่มากับ Owlbear Rodeo SDK โดยไม่มีแพตช์ SDK ที่ npm เสนอให้ในขณะจัดทำ ตัว Extension ไม่ได้เรียก UUID v3/v5/v6 ที่ระบุในรายงานโดยตรง
